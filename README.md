# Workmaxxxing 🚀

**Maximize your work. Own your time.**

Workmaxxxing is a modern, responsive productivity and task management SaaS landing page. It introduces a platform designed to help individuals and teams organize tasks, track project progress, manage deadlines, and improve productivity.

## 🌐 Live Demo

[View Workmaxxxing](https://workmaxxxxing.netlify.app/)

## ✨ Features

- **Responsive Navbar:** Navigation links with a mobile-friendly layout.
- **Hero Section:** Introduction to Workmaxxxing with prominent call-to-action buttons.
- **Features Section:** Highlights task management, progress tracking, deadline calendars, and team collaboration.
- **How It Works:** Explains the platform through three simple steps.
- **Pricing Section:** Displays Starter, Pro, and Enterprise plans.
- **Contact Section:** Contact form and business contact information.
- **Footer:** Organized navigation links and company information.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- HTML5
- Vite

## 💻 Getting Started

Follow these instructions to run the project locally.

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/hrrshpal/assignment-sg.git
```

**2. Navigate to the project directory**

```bash
cd assignment-sg
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```


## 🎨 Design Choices

1. The design follows a modern, minimal, and premium SaaS aesthetic.
2. Midnight navy (`#101827`) is used for dark sections to create a professional appearance.
3. Lime green (`#A3E635`) serves as the accent color for important elements and call-to-action buttons.
4. Light backgrounds are used in selected sections to create visual contrast and improve readability.
5. Tailwind CSS makes it easier to maintain consistent spacing, typography, and responsive layouts.
6. The layout uses responsive grids and flexible containers to provide a good experience across desktop, tablet, and mobile devices.
7. Clear navigation, structured content, and prominent call-to-action buttons help visitors explore the product easily.
